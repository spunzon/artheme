# Credits

The switcher is mine. The themes are not.

Each `themes/<name>/colors.toml` in this repo comes from someone else's work,
kept here unmodified so the palette stays faithful to the original. Wallpapers
are **not** redistributed here: `theme fetch <name>` downloads them from the
theme's own repository, where their licence applies.

| Theme | Source | Licence |
|---|---|---|
| `osaka-jade` | [omacom/omarchy](https://github.com/omacom/omarchy) (`quattro`, `themes/osaka-jade`) | see upstream |
| `pissarro` | [mattbbia/pissarro](https://github.com/mattbbia/pissarro) | MIT |
| `batou` | [HANCORE-linux/omarchy-batou-theme](https://github.com/HANCORE-linux/omarchy-batou-theme) | MIT |

The whole idea — one `colors.toml` per theme driving every app — is
[Omarchy](https://omarchy.org)'s, by Basecamp. This repo only ports the
mechanism to macOS; it shares no code with it.

If you own one of these themes and would rather not be listed here, open an
issue and I'll remove it.
