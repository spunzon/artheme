# Credits

The switcher is mine. The themes are not.

Each `themes/<name>/colors.toml` in this repo comes from someone else's work,
kept here unmodified so the palette stays faithful to the original.

**Wallpapers are not redistributed.** `artheme fetch <name>` downloads them from
the theme's own repository, where their licence applies, and the app pulls them
in the background the first time you apply a theme.

**`preview.jpg` is.** Each is a 600px recompression of the `preview.png` the
theme's own author publishes to show the theme off — 35 KB instead of 4 MB —
so the grid is full the moment the app opens, on a plane, before anything is
downloaded. Two themes have no upstream preview and use a downsized frame of
their own wallpaper instead. If you own one of these and would rather it were
not included, open an issue and it comes out.

| Theme | Source | Licence |
|---|---|---|
| `osaka-jade` | [omacom/omarchy](https://github.com/omacom/omarchy) (`quattro`, `themes/osaka-jade`) | see upstream |
| `pissarro` | [mattbbia/pissarro](https://github.com/mattbbia/pissarro) | MIT |
| `batou` | [HANCORE-linux/omarchy-batou-theme](https://github.com/HANCORE-linux/omarchy-batou-theme) | MIT |

The whole idea — one `colors.toml` per theme driving every app — is
[Omarchy](https://omarchy.org)'s, by Basecamp. This repo only ports the
mechanism to macOS; it shares no code with it.

If you own one of these themes and would rather not be listed here, open an
issue and I'll remove it.
